# V1.4.1 实施计划文档 —— 任务编辑弹窗化

> 补丁级 UI 迭代：卡片内联编辑在 160px 列宽里过挤，改为居中弹窗。

## 一、问题

列宽只有 ~160px，内联编辑表单（标题/描述/优先级/executor/截止 + 按钮）挤在一张卡片里，
字段折行、操作区局促。

## 二、设计

- 移除卡片内的内联编辑器。
- 新增**居中弹窗**（v1.4.1）：520px 宽、max-height 85%、玻璃风（`color-mix` +
  `backdrop-filter`，与活动抽屉同一视觉语言）、半透明遮罩。
- 弹窗头部：`编辑 <key>` + `项目 · 状态` 元信息 + × 关闭；描述 textarea 加大到 6 行。
- 行为：遮罩点击 / Escape 关闭（全局 keydown，与活动抽屉同模式）；保存携带
  `expectedRevision`（并发 409 语义不变）；保存后关闭并刷新。
- 无障碍：`role="dialog"` + `aria-modal` + 标题自动聚焦。

## 三、验收

- [x] 点击卡片「编辑」弹出居中弹窗，不再是卡片内联表单
- [x] 保存/取消/遮罩/Escape 均正常；并发 409 语义不变
- [x] check/build 全绿；上屏核对（3099 实例）

## 四、破坏性变更与回滚

纯面板改动，无 schema/路由变化。`git reset --hard v1.4.0` 可回滚。

## 五、完成定义
