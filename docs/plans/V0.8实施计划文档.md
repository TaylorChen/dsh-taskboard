# dsh-taskboard V0.8 实施计划

> 状态：待实施 · 基线 `v0.7.0` (`9ba12cd`) · 目标 `0.8.0` · ROADMAP **L5 知识层**
> 本文是实施依据。

---

## 一、背景（第一性原理）

L1–L4 已让任务「可流转、可规格、有证据、按依赖调度」。L5 是 agent 任务管理
**最大的增量价值**（ROADMAP）：Jira 的历史是死档案，agent 任务板的历史是
**活上下文**——每个完成的任务 = 一次执行的知识（问题、方案、证据、结论），
流回下一个任务能直接降低重复探索成本。v0.8 让历史从「审计」变成「输入」。

**核心洞察：经验卡不需要新字段。** done 任务已自带全部知识：`key`/`title`、
`spec.acceptanceCriteria`（要解决什么）、`evidence`（做了什么/产物/摘要）。
v0.8 做的是「检索 + 注入」两条链路，零 schema 变更。

## 二、范围

### 做

| 编号 | 工作项 | 破坏性 | 依赖 |
|---|---|---|---|
| **W1** | 经验检索：服务层按 workspace/label 检索相关 done 任务（经验卡） | 否 | — |
| **W2** | 创建注入：`task_create` 结果附带相关历史（模型可见） | 否 | W1 |
| **W3** | 会话注入：新会话启动时注入任务板上下文（opt-in） | 否 | W1 |

### 不做

| 不做 | 理由 |
|---|---|
| 经验卡落库/独立表 | done 任务本身就是卡；检索即归档 |
| 语义向量检索 | 标签 + workspace + 时间已够；向量检索是过度设计 |
| 自动总结教训 | 证据摘要即结论；额外模型轮次不值得 |

## 三、工作项详述

### W1 · 经验检索

**改动点（`src/service.ts`）。**

- `relatedExperience(filter: { projectId?, workspaceId?, label?, limit? })`：
  返回 done 任务按 `updatedAt` 降序的「经验卡」投影：
  `{ key, title, criteria: string[], artifacts: string[], summary: string }`
- `evidence.summary` 为空的任务排除（无内容的经验没有注入价值）

**验收**

- [ ] 返回 done 任务的经验卡投影，按更新时间倒序
- [ ] 无 summary 的 done 任务被排除
- [ ] 单测覆盖

### W2 · 创建注入

**改动点（`src/tool.ts`）。**

- `task_create` 成功后，用 `relatedExperience({ projectId, limit: 3 })` 取相关历史，
  在 render 输出追加：
  ```
  Related experience:
  - TB-7 <title> — <summary 前 120 字>
  ```
- 无历史时不追加；`taskValueSchema` 不变（render 是模型唯一视图）

**验收**

- [ ] 建任务后有相关 done 任务 → render 含 Related experience
- [ ] 无相关历史 → render 不变

### W3 · 会话注入（opt-in）

**改动点（`src/autoclaim.ts` 或新 `src/sessioncontext.ts`）。**

- Config `sessionContext: boolean`（默认 false）+ `sessionContextLimit`（默认 5）
- 监听 `agent/session-start`：注入一条 context 消息（`agent.inject`——不唤醒，
  下一个 pre-step 消费）：
  - 本会话 workspace 的未完成任务（open/in_progress，key + title，≤limit）
  - 相关 done 经验卡（同 workspace，≤limit，仅 key/title/summary 前 80 字）
- 注入总量有字数上限（防上下文膨胀）

**验收**

- [ ] 开启后新会话上下文含任务板摘要（真实 E2E 查会话日志）
- [ ] 默认关闭，行为不变

## 七、风险

| 风险 | 影响 | 缓解 |
|---|---|---|
| 注入挤占上下文 | 中 | opt-in + 字数上限 + top-K |
| 相关历史噪声 | 低 | 只取同 workspace/label 的 done 任务，limit 小 |
| session-start 事件时序 | 低 | `agent.inject` 在 pre-step 才消费，时序宽容 |
