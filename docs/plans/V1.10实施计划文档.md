# V1.10 实施计划文档 —「眼前一亮」功能清单

> 目标：把 dsh-taskboard 从「好用的看板」推向「与 agent 协作时让人眼前一亮的产品」——
> 任务本身具备**时间、记忆、证据、证明**四个可度量的维度。
> 原则：全部复用既有底座（活动流 v0.2、证据 v0.6、SSE v1.6、统计 v1.5/v1.9、经验 v0.8），
> 每个功能配**单测 + 真实浏览器 E2E**，先计划后实施，每步验证，本地提交 + tag，推送前等用户确认。

## 设计要点

### A1 — 时间线（纯逻辑 + 渲染）
- `src/client/timeline.ts`：`buildTimeline(entries, now)` → `{ events: 升序, segments: [{status, start, end}] }`；
  `enteredStatus` 从动作推断进入的状态（claimed → in_progress）；`STATUS_TIMELINE_COLOR` 状态色。
- 抽屉渲染：左侧 rail + 绝对定位彩色段（按生命周期比例）+ 每事件圆点 + describeEntry + 时间戳。
- 单测 3 项；浏览器验证：打开有活动流的任务（TB-5）断言事件升序渲染。

### A4 — 状态球
- `src/client/ball.ts`：`statusBall(status)` → `{ color, animation }`；`injectBallKeyframes()` 幂等注入
  `taskboard-pulse`（蓝脉动）与 `taskboard-breathe`（红呼吸）keyframes。
- 卡片标题旁 9px 圆点，`data-status-ball={status}`；未知状态降级为静止灰球（永不抛错）。
- 单测 7 项；浏览器 E2E：遍历 31 个球断言 animation-name 与 oklab 颜色。

### A5 — 履约证明书
- `src/client/evidence.ts`：`evidenceScore`（met/total/ratio）、`evidenceVerdict`（verified/partial/unverified）、
  `evidenceStamp`（key · date，容错）。
- 卡片证书：`data-certificate` + 徽章 + 逐条 ✓/✗ + artifact chip（`data-artifact`，点击复制 + Copied! 闪）。
- 单测 5 项；浏览器 E2E：证书渲染 + 剪贴板回读。

### A2/A3 — 记忆闭环
- 服务端：`GET /api/taskboard/experience?project=&limit=`（复用 relatedExperience）。
- 创建表单：`[data-experience]` 区展示 key/title/summary/artifacts。
- `bounceMemoryNote(reason, evidence)`：notes 变成 `bounce: <reason>; rejected evidence — <summary>; artifacts: …`。
- 单测 3 项（bounce）+ 既有经验测试；浏览器 E2E 自愈夹具（restore-tb5-fixture.sh）可重复运行。

### B1 — 脉冲条
- SSE effect 增加 liveState/lastChangeAt/changeCount/pulseTick；`[data-pulse-bar]` 渲染连接状态灯 + 变更计数 + 「last change x s」。
- 浏览器 E2E：Live 断言 + 外部写入触发计数增长。

### B3 — 首次运行
- 空板（tasks.length === 0）渲染 `[data-onboarding]`：三步循环 + 一键创建（复用 openCreate）。
- 浏览器 E2E：清空实例 3101 上断言引导卡出现 → 创建任务 → 引导卡消失。

### B2 — 人审决策面板
- awaiting_human 卡片新增 Review（`data-review`）→ `[data-review-panel]` 弹窗：完整证书 + 相关经验 + Confirm/Bounce。
- 浏览器 E2E：开面板 → 断言证书/标准/经验 → Confirm → 任务 done、面板关闭。

### C1 — 可执行验证
- `taskSpecSchema.verification`（加法 `.default('')`，不 bump DOMAIN_VERSION）；routes/tool/service 全链路透传；
  dispatch prompt 注入「RUN this command and report its actual output」；卡片 `[data-verification]` chip。
- 单测 4 项；浏览器 E2E：表单字段 → 卡片 chip → API 回读。
